Función cuadrática: f(x) = ax² + bx + c

Con a ≠ 0. Su gráfica es una parábola. Si a > 0 abre hacia arriba y el vértice es un mínimo; si a < 0 abre hacia abajo y el vértice es un máximo. Cuanto más grande es |a|, más cerrada es la parábola.

El vértice

xv = −b / (2a)

Luego yv = f(xv). El eje de simetría es la recta vertical x = xv. El corte con el eje y es (0, c).

Raíces y discriminante

x = (−b ± √Δ) / (2a)

Con Δ = b² − 4ac:

Δ > 0 dos raíces reales
Δ = 0 una raíz (doble)
Δ < 0 no corta el eje x

Ejemplo resuelto

f(x) = x² − 4x + 3

xv = 4/2 = 2; yv = 4 − 8 + 3 = −1 → V(2, −1), mínimo.
Δ = 16 − 12 = 4 > 0 → raíces x = 1 y x = 3, porque x² − 4x + 3 = (x − 1)(x − 3).
Rango: y ≥ −1.

En la vida real

Una pelota lanzada hacia arriba sigue h(t) = −5t² + 20t. El vértice t = 2 s da la altura máxima: h(2) = 20 m. También aparece en áreas, antenas parabólicas y puentes.

Tres formas de escribirla

Forma Ecuación Se ve fácil
General ax² + bx + c corte en y: c
Canónica (vértice) a(x − h)² + k vértice (h, k)
Factorizada a(x − x₁)(x − x₂) raíces x₁, x₂

Ej.: x² − 4x + 3 = (x − 2)² − 1 = (x − 1)(x − 3).

Transformaciones de y = x²

y = x² + k: sube k unidades (baja si k < 0).
y = (x − h)²: se mueve h unidades a la derecha (a la izquierda si h < 0).
y = −x²: se refleja, abre hacia abajo.
y = 3x²: más cerrada. y = ⅓x²: más abierta.

Cómo graficar una parábola

1. Mira el signo de a: hacia dónde abre.
2. Calcula el vértice V(xᵥ, yᵥ).
3. Marca el corte con el eje y: (0, c).
4. Halla las raíces si Δ ≥ 0.
5. Usa la simetría: el punto (0, c) tiene un «gemelo» en (2xᵥ, c).
6. Une los puntos con una curva suave.

Crece y decrece

Si a > 0, la función decrece para x < xᵥ y crece para x > xᵥ. Si a < 0 es al revés. El vértice marca el cambio. Ej.: f(x) = x² − 6x + 5 decrece en (−∞, 3) y crece en (3, +∞).

Problema de optimización

Con 40 m de cerca quieres un corral rectangular de área máxima. Si un lado mide x, el otro mide 20 − x, y el área es A(x) = x(20 − x) = −x² + 20x. El vértice está en x = −20/(2·(−1)) = 10. El área máxima es A(10) = 100 m²: un cuadrado de 10 × 10.

Ecuación vs. función

La función f(x) = x² − 9 es toda la parábola. La ecuación x² − 9 = 0 pregunta solo dónde f(x) vale cero: x = 3 y x = −3. Las soluciones de la ecuación son los cortes de la parábola con el eje x.
